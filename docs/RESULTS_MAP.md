# Manuscript-to-code result map

Every quantitative claim, figure, and table in the manuscript can be traced
to one script and one output file under `src/models/runs/`.

## Main text

| Manuscript section | Script / entry point | Output |
|---|---|---|
| Cohort and study population | `preprocess/src/run.py` (P4, P10) + `src/data/main.py` | `preprocess/artifacts/p4_samples/**/sample_stats.json` (not shipped; data) |
| Primary paired comparison | `scripts/run_experiment.py` | `runs/sc_common_paired/`, `runs/sce_common_paired/`, `runs/REPORT.md` |
| Deployment cohort & availability confounding | `scripts/run_deployment.py` | `runs/deployment/deployment_result.json` |
| Availability-only control (post hoc) | `scripts/run_avail_control.py` | `runs/avail_control/result.json` |
| Effect shape: timing and subgroups | `scripts/run_sensitivity.py` (freshness), `src/evaluation/cv_subgroup_interaction.py` | `runs/sensitivity/freshness_*/result.json`, `runs/cv_subgroup_interaction/interaction_result.json` |
| Methodological ablations | `scripts/run_ecg_globalnorm.py`, `scripts/run_ssl_inductive.py` | `runs/sensitivity/ecg_globalnorm/result.json`, `runs/sensitivity/ssl_inductive/result.json` |
| Tabular baselines vs deep encoders | `scripts/run_tabular_baselines.py` | `runs/baselines/results.json` |
| ECG-plus-tabular baselines | `scripts/run_ecg_tabular_baselines.py` | `runs/ecg_tabular/results.json` |
| Calibration & clinical utility | `src/evaluation/main_calibration.py`, `src/evaluation/dca.py`, `scripts/run_patient_dca.py` | `runs/main_calibration/`, `runs/dca/`, `runs/patient_dca/` |
| Competing-risk secondary analysis | `scripts/run_deephit.py` | `runs/deephit/` |
| External evaluation in eICU | `scripts/run_eicu_external.py`, `scripts/run_eicu_tabular_external.py` | `runs/eicu_external/`, `runs/eicu_tabular_external/results.json` |
| Subgroup performance (fairness audit) | `scripts/run_fairness_audit.py` | `runs/fairness/results.json` |
