## 核心发现

1. **不存在直接竞品仓库**。"脓毒症特异队列 + 12 导联 ECG 波形 + 多模态动态预测 + 多中心外部验证"的组合在 GitHub 公开仓库中完全空白。最近对手（SaAki_Sofa_benchmark、icu-sepsis-mimic）停留在 tabular + 静态 + 单库层面。这进一步确认了项目的差异化定位成立。

2. **高星组件仓库可以为第 5–6 月节省大量开发时间**。PyHealth（★1637）可直接提供 GRU/Transformer/TCN 的 EHR 适配实现，pycox（★991）和 Dynamic-DeepHit（★103）覆盖生存分析 + competing risks，hyperimpute（★201）覆盖缺失数据处理——这三个方向恰好对应文档第 4 节和第 3.6 节的核心模块。建议在临床分支复现阶段优先调研这 4 个仓库的 API，避免从零实现。

3. **mimic-code（★3325）是最重要的数据管线参照**。其 SQL 模板覆盖 sepsis-3 cohort selection、SOFA 计算、血管活性药剂量提取等关键步骤，DuckDB 管线应直接从其 MIMIC-IV 分支的 SQL 模板开始迁移而非从头编写。

4. **Cyclops（★95）提供了跨库漂移检测能力**。在 v1.2 引入 BlendedICU 多库扩展验证后，Cyclops 的子群性能分析和数据漂移检测模块可以直接嵌入评估 pipeline，提供 eICU / HiRID / AmsterdamUMC 之间的性能差异量化分析。

5. **Awesome-conformal-prediction（★1272）是 CP 方法选型的入口**。Mondrian CP、adaptive CP、class-conditional CP 等变体的论文和开源库均有收录，可在实现前快速对比各方案在 unbalanced sepsis data 上的适用性。
