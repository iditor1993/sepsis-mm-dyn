# SEPSIS-MM-DYN paired 队列功效分析方案与结果 v1.0

- 文档版本：v1.0
- 创建日期：2026-07-30
- 性质：**月 1 样本量分析核心交付物**（技术文档 §9.1/§18.1 Go/No-Go 前置）
- 代码：`src/evaluation/power_analysis.py`（可复跑；R=100 模拟 × B=300 患者级 bootstrap，seed=20260730）

---

## 1. 问题

主要 estimand：冻结 paired 队列上 SCE-common-paired vs SC-common-paired 的 **ΔiAUROC**（K=12 等权，成功标准 = 95% CI 下限 > 0）。ECG 增量价值的合理预期效应量约 **0.01–0.03**。在当前冻结的 24h 配对队列下，检测这些效应量的功效是多少？

## 2. 冻结 paired 测试集构成（实测）

| 指标 | 值 |
|---|---|
| 主网格（k≤11）样本 | 6,866 |
| 患者数 | 1,576 |
| **阳性 landmark 总数** | **152（2.2%）** |
| 逐 k 阳性 | k0:7, k1:16, k2:21, k3:26, k4:20, k5:20, k6:9, k7:9, k8:6, k9:4, k10:5, k11:9 |

⚠️ 12 个主 landmark 中 **8 个阳性数 <20**（技术文档 §5.1 单独报告阈），估计稳定性受限；主 ΔiAUROC 若任一 landmark 缺类别将按预登记标记「无法完整估计」。

## 3. 方法

- 双正态模型：每 landmark 按实测样本量与阳性数，生成共享结果 y 的配对得分（SC/SCE 残差相关 ρ=0.7）；
- 患者级聚类 bootstrap（B=300）估计 ΔiAUROC 的 95% percentile CI；
- R=100 次模拟重复，功效 = P(CI 下限 > 0)；
- 基线 AUROC_SC 敏感性：0.70 / 0.75 / 0.80。

## 4. 结果（`qa/power_analysis_paired.csv`）

| ΔiAUROC | AUROC_SC=0.70 | 0.75 | 0.80 |
|---|---|---|---|
| 0.01 | 0.12 | 0.07 | 0.13 |
| 0.02 | 0.23 | 0.31 | 0.39 |
| 0.03 | 0.40 | 0.40 | 0.52 |
| 0.05 | 0.76 | 0.86 | 0.90 |

## 5. 结论（硬数字）

1. **检测 Δ=0.01–0.02 的功效 ≤40%**：在当前冻结 paired 队列下，文献级预期效应量几乎注定得到 CI 跨 0 的结果；
2. **最小可检测效应（MDE @80% power）≈ 0.05**（AUROC_SC ≥0.75 时）；只有当 ECG 增量真实效应 ≥0.05 时，主要比较才有充分功效；
3. **设计纪律的代价已锁死**：24h 主配对窗已在 E-5 冻结，不能事后改 48h/72h 窗提升覆盖率（48h/72h 仅为敏感性分析）——这是正确的预注册纪律，但必须接受其功效后果；
4. **逐 k 阳性稀疏**：k=0 仅 7 例阳性，晚期 k 仅 4–9 例——landmark 级 AUROC 在这些时点本身不稳定，主结果解读需逐点标注。

## 6. 应对策略（按预登记路径，不新增自由度）

1. **负结果预案已就位**（技术文档 §18.1 Go/No-Go）：「ΔiAUROC 95% CI 下限 >0 未达到 → 转为亚组研究或负结果报告」。建议投稿策略即按此预案规划（ECG 增量在 CV-SOFA≥3 亚组的交互作用检验为预设次级问题，功效更集中于高危组）；
2. **主要统计依据报告**：论文中按本表如实报告 MDE=0.05，说明研究对 ≥0.05 效应有充分功效、对更小效应功效不足——这本身是有价值的设计透明度；
3. **部署队列作为关键次要分析**（样本量充足）：SC-common-all vs SCE-deployment 在全体 218,509 train / 72,067 test landmarks（阳性率同 2.34%，阳性 landmark 约 1,700）上评估，虽为次要 estimand，但事件数高一个数量级，应作为 ECG 增量证据链的承重分析之一；
4. **不做的事**：不改 24h 主窗、不扩大阳性定义、不按观察到的效应反向调整任何设计。

## 7. 复现

```bash
python src/evaluation/power_analysis.py   # 输出 qa/power_analysis_paired.csv
```
